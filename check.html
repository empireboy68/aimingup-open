What this proves, and what it does not

  1. It proves the list has not been edited since that month's code was published. Keep an old copy of the code and a later change cannot be hidden.
  2. It does not prove the list is true. Only the teachers in the room can do that, which is why every founder carries two names.
  3. If the code does not match, we changed something without publishing a new dated copy. That is a fair reason to ask us why.
