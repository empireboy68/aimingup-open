What a code proves, and what it does not

  • A code proves the list was not changed. It does not prove the list is true.
  • Only the two teachers named against a founder can say a club actually met.
  • Numbers are never reused. A lapsed place is retired, not handed on.
  • No money, voucher or gift to anyone under 18.
  • The five lessons are free, with no email address asked for.
