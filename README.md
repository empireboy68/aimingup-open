# AIMing Up: the open book

This is the outside copy of the AIMing Up founders list.

The list lives at aimingup.org/open. This page is the record that sits somewhere else, so that the monthly code cannot be quietly rewritten.

## How it works

Once a month, on the last day of the month, one line is added to `codes.txt`. Nothing is ever edited and nothing is ever removed. Every line carries the date it was written, and GitHub stamps every save with its own date. Anyone can look at the history and see when a line first appeared.

## What is here

- `codes.txt` the running record, one line per month
- `2026-10-list.txt` the founders list as it stood in October 2026, before any founder was issued
- `check.html` the checker. Open it in a browser, drop in a copy of the list you kept, and it says whether the code still matches.

## What a code proves

A code proves the list was not changed. It does not prove the list is true. Only the two teachers named against a founder can say a club actually met.

## The rules behind the list

- A founder was early and did the work. A number and a held place for ninety days. A badge only after a club has run a full term.
- Two names on every club: the teacher who ran it and the teacher who saw it.
- Numbers are never reused. A lapsed place is retired, not handed on.
- No money, voucher or gift to anyone under 18. Students are paid in status.
- The lesson files are free, all five, with no email address asked for.
